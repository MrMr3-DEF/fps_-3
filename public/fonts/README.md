# Science Gothic font

The WOFF2 files in this directory are self-hosted Google Fonts v5 subsets of
[Science Gothic](https://github.com/googlefonts/science-gothic), a Bank Gothic
revival. They cover Latin, Latin Extended, Cyrillic, Cyrillic Extended, and
Vietnamese. The variable files support weights 100–900. Other scripts use the
CSS fallback font.

The font is licensed under the SIL Open Font License 1.1. No purchase or
subscription is needed for web use. Keep `OFL-ScienceGothic.txt` with the font
files when redistributing them. The license and copyright notice came from the
[Google Fonts distribution](https://github.com/google/fonts/blob/main/ofl/sciencegothic/OFL.txt).

The WOFF2 files were downloaded from the official `fonts.gstatic.com` URLs in
the [Google Fonts Science Gothic stylesheet](https://fonts.googleapis.com/css2?family=Science+Gothic:wght@100..900&display=swap)
on 28 September 2026 and renamed by language subset.
